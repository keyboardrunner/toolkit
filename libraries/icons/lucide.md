**Lucide**

**Purpose**

Lucide is an open-source icon library with a large collection of consistent, customizable SVG icons.
Use it when a project needs interface icons, navigation icons, action icons, status icons, or other standard UI iconography.

**Use Lucide when**
•	The interface needs standard UI icons.
•	A button, input, menu, navigation item, or control needs an icon.
•	You need consistent iconography across a product.
•	Icons need to be customizable in size, stroke width, color, or other SVG properties.
•	You need icons that work well in modern web applications.
•	The project does not have its own established icon system.

**Examples**
Good use cases:
•	Search
•	Menu
•	Arrow navigation
•	Settings
•	User/account
•	Calendar
•	Bell/notifications
•	Edit
•	Delete
•	Download/upload
•	Share
•	Check/cross
•	Play/pause
•	Chevron controls

**Don’t use Lucide when**

•	The project already has an established icon library or design system.
•	The design requires a specific custom icon style that Lucide does not provide.
•	A brand-specific or custom illustration is required.
•	The icon is part of a logo or brand identity.

**Implementation**

When Lucide is selected for a project:
1.	Check the official repository and documentation for the current installation method.
2.	Use the package appropriate for the project’s framework.
3.	Prefer Lucide icons over manually drawing standard UI icons.
4.	Follow the project’s existing icon sizing and spacing conventions.
5.	Keep icon usage consistent throughout the interface.
6.	Do not manually recreate an icon that already exists in Lucide.
