# GSAP

https://github.com/greensock/GSAP

Professional-grade JavaScript animation library for creating complex, precise, and performant web animations.

## Use for

- Complex timelines
- Scroll-driven animations
- Page transitions
- Interactive UI motion
- Sequenced animations
- High-control animation effects

## AI

Use GSAP when an animation requires more control or sequencing than CSS transitions or simple browser APIs provide. Prefer simpler solutions for basic UI motion.
