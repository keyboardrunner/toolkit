# Libraries

This is a curated catalog of external libraries and resources for building web interfaces.

Before implementing a component from scratch:

1. Check this catalog.
2. Prefer an existing library when it fits.
3. Read the linked documentation before using it.
4. Do not introduce a dependency only for a trivial component.

## React

### Kobra
https://kobra.systems/components

React components for polished interfaces.

**Useful:** Carousel, Command Menu, Toast, Lightbox, etc.

**Stack:** React / Tailwind / shadcn

**AI:** Check Kobra before building common interactive components from scratch.
